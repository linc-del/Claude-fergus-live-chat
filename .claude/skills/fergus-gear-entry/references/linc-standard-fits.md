# Linc Electrical — standard fits (the gear we actually reach for)

Confirmed by Lincoln, 22 Jul 2026. This is the speed lever for voice entry: the everyday 80% of
gear should resolve to *these* brands, not a 24-row catalogue.

## How to use this
Linc's "standard" is usually a **short list of trusted brands**, not one SKU. So when a dictation
names an item in general terms:

1. Search the pricebook **constrained to Linc's preferred brands** for that item (below).
2. If one brand/variant is the clear everyday pick, lead with it as a one-tap "is it this?".
3. Show the other preferred-brand options (2–3) underneath — never the full catalogue of every
   brand in the book. The gear Linc *doesn't* use is noise, so leave it out.
4. Only ask about a spec when it actually changes the charge (amps on an RCBO, wattage on a
   downlight) — not colour/orientation unless they mention it.
